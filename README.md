# بيت المسك • BEIT AL-MUSK — دار العطور الملكية الفاخرة

> **Leave Your Mark** — متجر عطور إلكتروني فخم وتفاعلي ثلاثي الأبعاد مع أجنحة منفصلة للرجال والنساء، وواجهة دفع ذكية متكاملة، ونظام إدارة المنتجات للأدمن.

---

## 🌟 أبرز مميزات المتجر

### 1. المعرض التفاعلي ثلاثي الأبعاد (Dual 3D Showroom)
- منصتان دوارتان متكاملتان (جناح العطور الرجالية وجناح العطور الحريمية) مع إمكانية التنقل السلس بينهما.
- إضاءة بقعية ذكية (Dynamic Spotlight) تُركز على القنينة المختارة.
- عرض المواصفات والنفحات العطرية عند النقر فقط لتجربة بصرية نقية وفاخرة.

### 2. حزمة الدفع والشراء الذكية (Bespoke Checkout System)
- حقول مخصصة وسهلة: الاسم، رقم الهاتف المصري الموثق، والعنوان بالتفصيل.
- طرق دفع معتمدة: الدفع عند الاستلام، فودافون كاش، وإنستا باي (InstaPay).
- مصاريف شحن ثابتة (50 ج.م) لكافة المحافظات.
- توحيد كامل لجميع الأسعار بالجنيه المصري (`ج.م`).
- نافذة تأكيد ملكية أنيقة مع احتفال رقمي ورقم طلب مرجعي فريد (`#MUSK-2026-XXXX`).
- تسجيل وحفظ الطلبات سحابياً قبل فتح محادثة الواتساب وخصم المخزون آلياً.
- فاتورة رقمية معتمدة قابلة للعرض والطباعة أو الحفظ كـ PDF.

### 3. بوابة تحكم الأدمن وقاعدة البيانات السحابية (Admin & Supabase Architecture)
- قاعدة بيانات PostgreSQL مدارة عبر Supabase تشمل جداول: `perfumes`، `orders`، `coupons`، و `settings`.
- حماية أمنية مشددة عبر Row Level Security (RLS) وتسجيل دخول للمشرف عبر Supabase Auth مع رمز مرور سريع للطوارئ.
- دالة سيرفر آمنة `calculate_secure_order` لحساب الفواتير والكوبونات ومنع التلاعب بالأسعار.
- إضافة وتعديل وحذف العطور مع تحديد الجناح (رجالي / حريمي).
- رفع وتغيير صور العطور مع ضغط تلقائي ذكي يحافظ على سرعة الموقع.
- إعدادات أرقام التواصل، محافظ فودافون كاش، وحسابات إنستا باي.
- إدارة أكواد الخصم والخصومات العامة.
