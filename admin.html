إعدادات الربط السحابي مع Google Firebase

مزامنة فورية للأسعار والمخزون والطلبات عبر كل أجهزة العالم

🟡
الوضع الحالي: وضع محلي (Local Mode)

البيانات تُحفظ في ذاكرة هذا المتصفح فقط. لربطها سحابياً لجميع الزوار، أدخل بيانات مشروعك في Firebase أدناه.

📖 كيف أحصل على بيانات Firebase مجاناً في دقيقتين؟ اضغط للعرض

1. افتح console.firebase.google.com وسجل بحساب Google مجاناً.

2. اضغط Create a project وأعطه اسماً (مثل: beit-al-musk).

3. من القائمة الجانبية، اختر Build -> Firestore Database واضغط Create Database (اختر Start in test mode).

4. اذهب إلى إعدادات المشروع (Project Settings ⚙️) ثم انزل لأسفل واضغط على أيقونة الويب </> لنسخ مفاتيح الـ firebaseConfig.

⚡

إعدادات قاعدة بيانات Supabase (PostgreSQL & Auth)

SUPABASE V2 • ROW LEVEL SECURITY • SECURE ORDERS

🟡
حالة الاتصال: محلي (Local Mode)

أدخل رابط مشروع Supabase والمفتاح العام (anon key) لربط قاعدة البيانات PostgreSQL وتفعيل صلاحيات RLS.

📖 خطوات تجهيز Supabase في دقيقتين: اضغط للعرض

1. افتح supabase.com وأنشئ مشروعاً مجانياً جديداً.

2. اذهب إلى SQL Editor في لوحة Supabase، والصق كود ملف supabase-schema.sql واضغط Run لإنشاء الجداول والدوال وصلاحيات RLS.

3. اذهب إلى Project Settings ⚙️ > API وانسخ Project URL و anon public key وضعهما في الحقول بالأسفل.

4. اذهب إلى Authentication > Users وأضف بريدك الإلكتروني وكلمة المرور لتسجيل الدخول كأدمن معتمد.
